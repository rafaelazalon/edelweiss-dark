# Pixel art credits — Edelweiss: Dark Fantasy

The pixel art in `assets/lpc/` comes from the **Liberated Pixel Cup (LPC)** project.
These files are dual-licensed **CC-BY-SA 3.0** and **GPL 3.0** (some also OGA-BY 3.0).
If you redistribute them, keep this file and these credits, and share any modified
versions of the images under the same license.

The images were recoloured, cropped, mirrored into seamless tiles and combined into
sprite sheets for this game.
